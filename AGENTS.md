# Repository instructions

## Purpose
This repository defines Phantom's Shortcuts specification, implementation guidance, security considerations, examples, and changelog.

## Layout
The specification and all contribution guidance live in `README.md`.

## Working in this repository
- Keep schema fields, examples, security guidance, and changelog entries consistent with each other.
- Follow the token-creator and hosting guidance documented in `README.md`.
- The repository does not define build, test, or lint commands; validate the Markdown and JSON examples affected by a change.
